如何添加新故事
  1. 目录约定：连载放 series/<系列slug>/epNN-主题/；单本放 oneshots/<书名slug>/。新系列可复制 series/_template/。
  2. 在对应文件夹放好 index.html 与 assets/；系列分册的角色设定写在该系列根目录的 character-bible.md / refs/。
  3. 打开根目录 stories.json：在 stories 数组里复制一条记录，改封面、标题、简介、链接路径。
  4. 连载故事加上 "series": "中文系列名"，并在同文件的 seriesCatalog 登记该系列（名称需一致）；单本不要填 series。
  5. 通过 Nginx 等 HTTP 方式访问本站（不要用双击本地文件预览），保存后点「强制刷新」，新卡片会出现在对应分区。
