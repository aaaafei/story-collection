如何添加新故事
  1. 目录约定：连载放 series/<系列slug>/epNN-主题/；单本放 oneshots/<书名slug>/。新系列可复制 series/_template/。
  2. 在对应文件夹放好 index.html 与 assets/；系列分册的角色设定写在该系列根目录的 character-bible.md / refs/。
  3. 高清图放入该册 assets/src/ 后，在仓库根目录执行 python tools/optimize_images.py <绘本目录>，生成网页内页与 cover.jpg（说明见 tools/README.md）。
  4. 打开根目录 stories.json：在 stories 数组里复制一条记录；封面请用 .../assets/cover.jpg。加上 createdAt（如 2026-09-25T08:30:00+08:00）。页顶「最新故事」取最近 3 本；系列正文仍按集数从早到晚排。
  5. 连载故事加上 "series": "中文系列名"，并在同文件的 seriesCatalog 登记该系列（名称需一致）；单本不要填 series。
  6. 本机可点页顶「同步新故事」：先运行 python tools/sync_server.py，用弹出的本地地址打开本站，选择系列后会查找 Notion 里还没收录的分册并生成文件。需要在 tools/.env 配置 Notion 集成令牌。
  7. 通过 Nginx 等 HTTPS 方式访问本站（不要用双击本地文件预览），保存后点「强制刷新」，新卡片会出现在对应分区。
  8. 本站为轻量 PWA：可用浏览器「安装应用 / 添加到主屏幕」；不做离线缓存，上架故事流程不变。

同步新故事

选择要检查的系列。助手会去 Notion 对应目录里找还没收录的分册，再下载插画、生成绘本页面并登记到书架。
