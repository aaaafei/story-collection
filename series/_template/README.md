# 系列模板（复制本目录后改名）

复制为 `series/<你的系列英文slug>/`，再按需改文件内容。

```
series/<slug>/
├── README.md
├── character-bible.md
├── style-guide.md
├── prompt-template.md
├── workflow.md
├── refs/
│   └── README.md
└── ep01-your-first-book/
    ├── index.html
    ├── assets/
    └── prompts.md
```

不要多个系列共用一份 character-bible；每个系列独立维护角色与参考图。
