# 蔷薇公主系列 · 角色圣经

> **唯一真相来源。** 各册 `prompts.md` 禁止另写冲突的外形描述。  
> 改外形时：先改本文 + 更新 `refs/` 标准照，再决定是否重渲旧书。  
> 最后更新：2026-09-13

---

## 使用方式

生成任何一页插画时：

1. 从下方复制本页出场角色的「Prompt 固定段」（原样粘贴，不要改写）
2. 挂上 `refs/` 中对应标准照作为参考图
3. 仅在「本页可变段」里写场景、动作、表情

## 主角

### 蔷薇公主（姐姐）

| 项 | 锁定内容 |
|---|---|
| 身份 | 系列主角、姐姐；彩虹 / 百花城堡的小公主，爱种花 |
| 年龄感 | Q 版幼儿公主（约 5–6 岁观感） |
| 发型发色 | **浅棕色微卷长发**（禁止金发、黑长直、短发） |
| 发饰 | 粉色小花发饰 |
| 服装 | 粉红色蓬蓬公主裙 |
| 气质 | 温柔爱花；也可活泼调皮（按本册剧情，但外形不变） |
| 标志道具（可选出场） | 小铲子、小水壶、闪光玫瑰种子 |

**Prompt 固定段（复制用）：**
```
浅棕色微卷长发、头戴粉色小花发饰、穿粉红色蓬蓬公主裙的蔷薇公主（Q版软萌小公主）
```

**禁止项：** 金发 / 金冠卷发、换裙色、成人比例、写实脸、无发饰。

**标准参考图：** `refs/rose-princess-front.jpg`、`refs/rose-princess-bust.jpg`（待放入）

### 玫瑰公主（妹妹 / 玫瑰小公主）

| 项 | 锁定内容 |
|---|---|
| 身份 | 蔷薇公主亲手种出的宝贝公主、妹妹 |
| 年龄感 | Q 版幼儿公主，可比姐姐略小一点 |
| 发型发色 | **蓝色软卷发** |
| 发饰 | 蓝色小花发饰 |
| 服装 | 蓝色蓬蓬公主裙（可带少量蕾丝细节，主色必须是蓝） |
| 眼睛 | 亮晶晶，像小星辰 |
| 气质 | 软萌、勇敢、机灵 |

**Prompt 固定段（复制用）：**
```
蓝色软卷发、头戴蓝色小花发饰、穿蓝色蓬蓬公主裙、眼睛亮晶晶的玫瑰公主（Q版软萌小公主）
```

**禁止项：** 粉裙、棕发/金发、成人比例、写实脸、无发饰。

**标准参考图：** `refs/blue-rose-princess-front.jpg`、`refs/blue-rose-princess-bust.jpg`（待放入）
