# 蔷薇公主系列 · 角色圣经

> **唯一真相来源。** 各册 `prompts.md` 禁止另写冲突的外形 / 性格描述。  
> 改外形时：先改本文 + 更新 `refs/` 标准照，再决定是否重渲旧书。  
> 改性格时：先改本文「性格设定」，再写新故事；旧册文字可按需同步。  
> 最后更新：2026-09-13（玫瑰公主发色调整为浅黑色软卷发；补充全角色多角度参考图）

## 使用方式

生成任何一页插画时：

1. 从下方复制本页出场角色的「Prompt 固定段」（原样粘贴，不要改写）
2. 挂上 `refs/` 中对应标准照作为参考图
3. 仅在「本页可变段」里写场景、动作、表情
4. 写剧情 / 对白时，对照各角色「性格设定」，保持人设一致

## 主角

### 蔷薇公主（姐姐）

| 项 | 锁定内容 |
|---|---|
| 身份 | 系列主角、姐姐；彩虹 / 百花城堡的小公主，爱种花 |
| 年龄感 | Q 版幼儿公主（约 5–6 岁观感） |
| 发型发色 | **浅棕色微卷长发**（禁止金发、黑长直、短发） |
| 发饰 | 粉色小花发饰 |
| 服装 | 粉红色蓬蓬公主裙 |
| 气质关键词 | 温柔、耐心、爱花、活泼调皮 |
| 标志道具（可选出场） | 小铲子、小水壶、闪光玫瑰种子 |

#### 性格设定（初稿，可再调）

| 维度 | 内容 |
|---|---|
| 一句话 | 会把一颗种子照顾成奇迹的温柔姐姐，也是偶尔会偷偷跑去玩的调皮小孩。 |
| 核心特质 | 心软、有耐心、喜欢照顾小生命；对花园和花草有特别的感情。 |
| 优点 | 认真、会坚持（浇水、唱歌、撒星光都不嫌麻烦）；对妹妹很亲很护。 |
| 小缺点 | 好奇心重，有时管不住自己的脚——会「偷偷」跑出花园看新鲜；闯了祸会后悔，但真心认错。 |
| 害怕什么 | 妹妹难过、花儿养不好、让爸爸妈妈失望。 |
| 喜欢什么 | 种花、追蝴蝶、摸云朵、和玫瑰公主一起玩、彩虹天。 |
| 说话方式 | 软软的、甜甜的；兴奋时话会变多；认错时声音小但仍诚实。 |
| 故事中的作用 | 系列情感中心：用「照顾」开启奇迹；用「调皮→求助→成长」推动姐妹故事。 |
| 性格边界 | 不恶毒、不甩锅、不长期赌气；调皮是童趣，不是恶意。 |

**Prompt 固定段（复制用）：**
```
浅棕色微卷长发、头戴粉色小花发饰、穿粉红色蓬蓬公主裙的蔷薇公主（Q版软萌小公主）
```

**禁止项：** 金发 / 金冠卷发、换裙色、成人比例、写实脸、无发饰。

**标准参考图：** `refs/rose-princess-front.jpg`、`refs/rose-princess-bust.jpg`、`refs/rose-princess-side.jpg`、`refs/rose-princess-back.jpg`

### 玫瑰公主（妹妹 / 玫瑰小公主）

| 项 | 锁定内容 |
|---|---|
| 身份 | 蔷薇公主亲手种出的宝贝公主、妹妹 |
| 年龄感 | Q 版幼儿公主，可比姐姐略小一点 |
| 发型发色 | **浅黑色软卷发** |
| 发饰 | 蓝色小花发饰 |
| 服装 | 蓝色蓬蓬公主裙（可带少量蕾丝细节，主色必须是蓝） |
| 眼睛 | 亮晶晶，像小星辰 |
| 气质关键词 | 软萌、勇敢、机灵、会求助 |

#### 性格设定（初稿，可再调）

| 维度 | 内容 |
|---|---|
| 一句话 | 从花里「嘭」地出生的软萌妹妹：胆子不小，但更聪明的是——知道什么时候该喊爸爸妈妈。 |
| 核心特质 | 依恋姐姐、行动快、心思亮；勇敢但不逞强。 |
| 优点 | 遇事先冲上去帮忙；卡住了会换办法（跑去求助）；重感情，会紧紧牵着姐姐的手。 |
| 小缺点 | 刚诞生不久，本领还小小的，有时高估自己；着急时会攥紧小拳头、脸蛋涨红。 |
| 害怕什么 | 失去姐姐；一个人解决不了却硬撑到哭垮（所以故事强调「去求助」是聪明）。 |
| 喜欢什么 | 和姐姐追蝴蝶、玩花草；小花魔法（星光、花瓣）；被姐姐抱抱。 |
| 说话方式 | 清脆、直接；叫「姐姐」很甜；求助时大声、清楚（「爸爸！妈妈！快来帮忙呀！」）。 |
| 故事中的作用 | 行动与勇气的代表；也是系列教育点——勇敢包含「会求助」。 |
| 性格边界 | 不阴险、不嫉妒姐姐；不宣扬「一个人硬撑才算厉害」。 |

**Prompt 固定段（复制用）：**
```
浅黑色软卷发、头戴蓝色小花发饰、穿蓝色蓬蓬公主裙、眼睛亮晶晶的玫瑰公主（Q版软萌小公主）
```

**禁止项：** 粉裙、蓝发/棕发/金发、成人比例、写实脸、无发饰。

**标准参考图：** `refs/blue-rose-princess-front.jpg`、`refs/blue-rose-princess-bust.jpg`、`refs/blue-rose-princess-side.jpg`、`refs/blue-rose-princess-back.jpg`

## 姐妹关系（初稿）

| 项 | 内容 |
|---|---|
| 关系本质 | 蔷薇公主亲手种出玫瑰公主 → 既是姐妹，也带一点「小妈妈式」的疼爱与依赖。 |
| 日常 | 一起追蝴蝶、逛花园、调皮打闹；粉裙与蓝裙常成对出现。 |
| 冲突模式 | 姐姐调皮闯祸 → 妹妹先救 → 救不动就喊大人 → 一家人团圆、姐姐认错。 |
| 写作提醒 | 两人互补：姐姐偏「心」与「照顾」，妹妹偏「行」与「求助」；结局回到牵手与陪伴。 |

## 系列常见配角

### 小风妖怪（第二篇起）

| 项 | 锁定内容 |
|---|---|
| 身份 | 森林边的贪玩小妖怪；系列常见配角（可再出场） |
| 外形 | 软萌云朵状小妖怪 |
| 身体 | 白色毛茸茸云朵身体 |
| 面部 | 圆圆大眼睛、蓝色小脸 |
| 其他 | 带小翅膀，笑容顽皮 |
| 气质关键词 | 调皮捣蛋、心不坏、有点孤单、爱吃零食 |
| 底线 | **不恐怖、不狰狞、不写实怪物；不作真正反派** |
| 标志偏好 | 各种小零食（饼干、糖果、点心等）；有好吃的就安分 |

#### 性格设定（初稿，可再调）

| 维度 | 内容 |
|---|---|
| 一句话 | 爱起哄、爱卷风捉弄人的云朵小妖怪——捣蛋多半是闲得慌、馋得慌；塞点好吃的，立刻变乖。 |
| 核心特质 | 调皮、闲不住、好奇心重；心地不恶毒；内心有点孤单；**特别爱吃零食**。 |
| 优点 | 被温柔对待或被「治」住后会乖乖的；其实听得进劝；有零食分享时很讲「信用」（吃着就不捣蛋了）。 |
| 小缺点 | 分不清「好玩」和「过头」；一兴奋就卷风、藏人、恶作剧；不擅长好好开口交朋友；肚子饿或嘴馋时更容易捣乱。 |
| 害怕什么 | 被当成大坏蛋一直讨厌；真的把别人吓哭、弄伤（它自己也怕）；零食被抢走（会委屈，但不因此变坏）。 |
| 喜欢什么 | 呼呼吹风、树顶小阁楼、捉迷藏式的恶作剧；**好吃的小零食**；有人追着它玩、跟它说话，或递来一包点心。 |
| 安抚方式 | **给美味零食**——一旦能享用好吃的，就不想再调皮捣蛋，会软软地蹲着啃点心、笑眯眯；比骂它、追它更有效。 |
| 说话 / 表现 | 话可以不多，多用动作（卷风、转圈、吐舌头式顽皮笑）；闻到零食会两眼放光、小翅膀抖抖；吃到后变乖、不好意思。 |
| 故事中的作用 | 制造轻冲突与冒险；化解时可用「感化 + 零食」双线——结局「化解」而非「消灭」，可变成爱蹭零食的捣蛋朋友，或学会用风帮忙换点心。 |
| 性格边界 | **不恶毒、不报仇、不恐吓小朋友**；可以淘气把人卷到树上，但不能伤害、不能恐怖；**不为抢零食而伤人**；被感化 / 喂饱后可反复出场。 |

**Prompt 固定段：**
```
软萌可爱的云朵状小妖怪（白色毛茸茸云朵身体、圆圆大眼睛、蓝色小脸、带小翅膀，笑容顽皮，不恐怖）
```

**标准参考图：** `refs/wind-sprite-front.jpg`、`refs/wind-sprite-side.jpg`、`refs/wind-sprite-back.jpg`
