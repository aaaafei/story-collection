> **唯一真相来源。** 各册 `prompts.md` 禁止另写冲突的外形 / 性格描述。  
> 改外形时：先改本文 + 更新 `refs/` 标准照，再决定是否重渲旧书。  
> 改性格时：先改本文「性格设定」，再写新故事；旧册文字可按需同步。  
> 最后更新：2026-09-16（新增梦境搭档：噩梦妖怪与美梦仙子角色设定，供后续梦境主题故事使用；此前：2026-09-14 新增玫瑰公主·小宝贝形态与百花幼儿园魔法设定，供 ep07 使用；再此前：新增地下公主角色与地下城堡世界设定，供 ep05 使用）

## 使用方式

生成任何一页插画时：

1. 从下方复制本页出场角色的「Prompt 固定段」（原样粘贴，不要改写）
2. 挂上 `refs/` 中对应标准照作为参考图（外形一致；**故事页姿态不要照搬标准照的正面站姿**）
3. 仅在「本页可变段」里写场景、视角、肢体动作、表情（详见 `style-guide.md` / `prompt-template.md`）
4. 写剧情 / 对白时，对照各角色「性格设定」，保持人设一致
5. 系列出图时人物视角要有变化，并带有清晰肢体动作，避免页页正面/侧面呆站

## 主角

### 蔷薇公主（姐姐）

| 项 | 锁定内容 |
|---|---|
| 身份 | 系列主角、姐姐；彩虹 / 百花城堡的小公主，爱种花 |
| 年龄感 | Q 版幼儿公主（约 5–6 岁观感） |
| 发型发色 | **浅棕色微卷长发**（禁止金发、黑长直、短发） |
| 发饰 | 粉色小花发饰 |
| 服装 | 粉红色蓬蓬公主裙 |
| 气质关键词 | 温柔、耐心、爱花、活泼调皮 |
| 标志道具（可选出场） | 小铲子、小水壶、闪光玫瑰种子 |

#### 性格设定（初稿，可再调）

| 维度 | 内容 |
|---|---|
| 一句话 | 会把一颗种子照顾成奇迹的温柔姐姐，也是偶尔会偷偷跑去玩的调皮小孩。 |
| 核心特质 | 心软、有耐心、喜欢照顾小生命；对花园和花草有特别的感情。 |
| 优点 | 认真、会坚持（浇水、唱歌、撒星光都不嫌麻烦）；对妹妹很亲很护。 |
| 小缺点 | 好奇心重，有时管不住自己的脚——会「偷偷」跑出花园看新鲜；闯了祸会后悔，但真心认错。 |
| 害怕什么 | 妹妹难过、花儿养不好、让爸爸妈妈失望。 |
| 喜欢什么 | 种花、追蝴蝶、摸云朵、和玫瑰公主一起玩、彩虹天。 |
| 说话方式 | 软软的、甜甜的；兴奋时话会变多；认错时声音小但仍诚实。 |
| 故事中的作用 | 系列情感中心：用「照顾」开启奇迹；用「调皮→求助→成长」推动姐妹故事。 |
| 性格边界 | 不恶毒、不甩锅、不长期赌气；调皮是童趣，不是恶意。 |

**Prompt 固定段（复制用）：**
```
浅棕色微卷长发、头戴粉色小花发饰、穿粉红色蓬蓬公主裙的蔷薇公主（Q版软萌小公主）
```

**禁止项：** 金发 / 金冠卷发、换裙色、成人比例、写实脸、无发饰。

**标准参考图：** `refs/rose-princess-front.jpg`、`refs/rose-princess-bust.jpg`、`refs/rose-princess-side.jpg`、`refs/rose-princess-back.jpg`

### 玫瑰公主（妹妹 / 玫瑰小公主）

| 项 | 锁定内容 |
|---|---|
| 身份 | 蔷薇公主亲手种出的宝贝公主、妹妹 |
| 年龄感 | Q 版幼儿公主，可比姐姐略小一点 |
| 发型发色 | **浅黑色软卷发** |
| 发饰 | 蓝色小花发饰 |
| 服装 | 蓝色蓬蓬公主裙（可带少量蕾丝细节，主色必须是蓝） |
| 眼睛 | 亮晶晶，像小星辰 |
| 气质关键词 | 软萌、勇敢、机灵、会求助 |

#### 性格设定（初稿，可再调）

| 维度 | 内容 |
|---|---|
| 一句话 | 从花里「嘭」地出生的软萌妹妹：胆子不小，但更聪明的是——知道什么时候该喊爸爸妈妈。 |
| 核心特质 | 依恋姐姐、行动快、心思亮；勇敢但不逞强。 |
| 优点 | 遇事先冲上去帮忙；卡住了会换办法（跑去求助）；重感情，会紧紧牵着姐姐的手。 |
| 小缺点 | 刚诞生不久，本领还小小的，有时高估自己；着急时会攥紧小拳头、脸蛋涨红。 |
| 害怕什么 | 失去姐姐；一个人解决不了却硬撑到哭垮（所以故事强调「去求助」是聪明）。 |
| 喜欢什么 | 和姐姐追蝴蝶、玩花草；小花魔法（星光、花瓣）；被姐姐抱抱。 |
| 说话方式 | 清脆、直接；叫「姐姐」很甜；求助时大声、清楚（「爸爸！妈妈！快来帮忙呀！」）。 |
| 故事中的作用 | 行动与勇气的代表；也是系列教育点——勇敢包含「会求助」。 |
| 性格边界 | 不阴险、不嫉妒姐姐；不宣扬「一个人硬撑才算厉害」。 |

**Prompt 固定段（复制用）：**
```
浅黑色软卷发、头戴蓝色小花发饰、穿蓝色蓬蓬公主裙、眼睛亮晶晶的玫瑰公主（Q版软萌小公主）
```

**禁止项：** 粉裙、蓝发/棕发/金发、成人比例、写实脸、无发饰。

**标准参考图：** `refs/blue-rose-princess-front.jpg`、`refs/blue-rose-princess-bust.jpg`、`refs/blue-rose-princess-side.jpg`、`refs/blue-rose-princess-back.jpg`

#### 小宝贝形态（ep07 婴儿时期专用）

> **时间线：** 紧接 ep01「蔷薇公主的玫瑰公主花」之后——玫瑰公主刚诞生不久、还是小宝贝。
> 本形态仅供 ep07 等「婴儿时期」故事使用；ep02 起的故事恢复「幼儿形态」。两者外形标记（浅黑色软卷毛、蓝色小花发饰、蓝裙、亮晶晶眼睛）一致，仅年龄感与体态不同。

| 项 | 锁定内容 |
|---|---|
| 年龄感 | 刚诞生不久的小婴儿（Q 版软萌小团子，约 0–1 岁观感） |
| 发型发色 | **浅黑色软软小卷毛**（细软胎发感，带一两根翘翘的小呆毛） |
| 发饰 | 小小的蓝色小花发饰（软布材质，系在软毛上） |
| 服装 | 蓝色小连体蓬蓬裙（带白色蕾丝小花边）；外出加一件浅蓝色小斗篷 |
| 体型 | 圆滚滚小团子、脸蛋肉嘟嘟、手脚胖乎乎（小藕节感）；通常被抱在怀里、躺摇篮里或坐在推车里 |
| 眼睛 | 亮晶晶，像小星辰（与幼儿形态一致） |
| 状态 | 不会走路、不会说话：只会「咿咿呀呀」、挥小胖手、咯咯笑、伸小胖手要抱抱 |
| 气质关键词 | 软萌、爱笑、爱看姐姐、不怕陌生 |

**性格设定（小宝贝形态，初稿）：**

| 维度 | 内容 |
|---|---|
| 一句话 | 还不会走、不会说的小团子，全靠咿咿呀呀、小胖手和咯咯笑表达一切——她的笑声能把最调皮的风妖怪都「治」住。 |
| 核心特质 | 爱笑、爱被抱抱、爱看姐姐；想姐姐时指着门口咿咿呀呀；对世界充满好奇，看见会飞的云朵妖怪只觉得好玩、不害怕。 |
| 说话方式 | 只会「咿咿呀呀」「咯咯咯」；想姐姐时会含含糊糊地叫「姐……姐……」 |
| 故事中的作用（ep07） | 全篇情感中心：留在家想念姐姐 → 和爸爸妈妈一起去接姐姐 → 用咯咯笑和胖乎乎的小手「感化」捣蛋的风妖怪。 |
| 性格边界 | 不写成会走路、会跑跳、会完整说话的幼儿；保持小婴儿软萌感，不搞笑过火。 |

**Prompt 固定段（复制用）：**
```
刚诞生不久的小宝贝玫瑰公主（Q版软萌小婴儿）：浅黑色软软小卷毛、头戴小小的蓝色小花发饰、穿蓝色小连体蓬蓬裙（带白色蕾丝小花边）、脸蛋肉嘟嘟、眼睛亮晶晶像小星辰，圆滚滚的小团子，被抱在怀里
```

**禁止项：** 幼儿体态 / 站立奔跑 / 说完整的话、金发棕发、粉裙红裙、成人比例、写实脸、无发饰。

**标准参考图（待补）：** `refs/rose-baby-front.jpg`、`refs/rose-baby-bust.jpg`（ep07 出图前生成）

## 好友公主

### 地下公主（地下城堡的小主人）

| 项 | 锁定内容 |
|---|---|
| 身份 | 地下城堡的小主人；蔷薇公主和玫瑰公主的好朋友（ep05 首登场，可再出场） |
| 年龄感 | Q 版幼儿公主，与两位小公主同龄（约 5 岁观感） |
| 发型发色 | **浅蓝色软卷发**（齐肩中长、空气刘海，发尾自然内扣微卷；头发里散落极细银闪） |
| 发饰 | 银色星星发饰：右侧鬓边一颗大五角星（带闪粉），旁缀一小串珍珠细链；头顶后方另有两颗小星星（一大一小） |
| 耳饰 | 左右各一枚银色星芒垂坠耳环（小星连细链、坠小钻） |
| 颈饰 | 珍珠细颈链（choker），正中央缀一颗小星钻 |
| 服装 | **黑色露肩蓬蓬公主裙**：心形领口、荷叶边小飞袖（像一对小翅膀），裙身散布银色星星与小亮片，裙摆微透薄纱 |
| 鞋子 | 赤足（粉嫩小脚丫） |
| 眼睛 | 紫蓝色渐变眼眸，瞳仁里有细碎星光点；长睫毛 |
| 皮肤 | 白皙偏冷，两颊粉橘色圆腮红 |
| 气质关键词 | 安静、温柔、神秘、向往光亮 |

#### 性格设定

| 维度 | 内容 |
|---|---|
| 一句话 | 住在地底城堡、从没见过阳光的安静小公主——最想要的礼物，是暖融融的天光。 |
| 核心特质 | 安静温柔、心思细腻；常年生活在灯照的地底，对光亮和温暖格外珍惜。 |
| 优点 | 好客、体贴；熟悉地底的星光魔法，能开启城堡的星光屏障；朋友来了会早早在门口张开双臂等。 |
| 小缺点 | 有点怕黑、有点孤单；羡慕地面的阳光，容易因为没人陪伴而闷闷不乐；不太敢主动开口交朋友。 |
| 害怕什么 | 黑暗、孤独；弄丢朋友送来的光亮；自己的魔法守不住朋友。 |
| 喜欢什么 | 亮晶晶的水晶灯、萤光小植物、星光、朋友来做客、暖融融的光；花蜜果汁；被朋友拍手叫好。 |
| 不喜欢 | 冷风、乱糟糟的狂风、黑漆漆没有灯的角落；一个人吃饭。 |
| 说话方式 | 轻轻的、软软的、尾音上扬；开心时会欢呼拍手，声音甜甜的；说心愿时会低头小声、双手交叠在膝上。 |
| 口癖示例 | 「哇——好暖好亮呀！」「这是……真的阳光吗？」「你们愿意来陪我，我好开心……」 |
| 故事中的作用 | ep05 的核心朋友：用「想要阳光」的心愿引出天降神灯，与两位小公主一起守护神灯；也是「被陪伴、被温暖」的一方，教会主角们分享与守护。 |
| 成长弧 | 从「独自守着冷灯的孤单小公主」→「被神灯和朋友照亮、敢用星光魔法站出来守护大家」。 |
| 性格边界 | 不阴郁、不闹脾气；是温柔可爱的小朋友，不是冷冰冰的形象；再难过也不会说难听的话。 |

#### 魔法与能力

| 项 | 内容 |
|---|---|
| 星光屏障 | 双手向上托举，头顶浮起一圈银色星光罩，可笼罩整个大厅、稳住乱飞的神灯（ep05 第 11 页首次施展） |
| 星路灯火 | 熟悉城堡里每一盏水晶灯与萤光植物的位置，能凭记忆在黑暗里带路 |
| 光感 | 对冷光（水晶灯）和暖光（神灯/阳光）特别敏感，一眼能分辨温度 |

#### 标志性动作与表情（出图可参考）

| 场景 | 动作/表情 |
|---|---|
| 迎接朋友 | 站在城堡门口张开双臂，笑容甜甜 |
| 说出心愿 | 坐在窗边石椅上，双手交叠放膝，微微低头、眼神带羡慕 |
| 收到惊喜 | 双手捧在脸颊两侧，眼睛亮晶晶期待 |
| 接住神灯 | 仰头伸手去接飘来的灯，表情专注惊喜 |
| 开心时 | 双手举在胸前开心拍手，笑眼弯弯 |
| 起风紧张 | 双手护住裙摆，头发被吹乱、表情着急 |
| 施法守护 | 双手向上托举，头顶星光环绕，表情认真 |
| 好奇时 | 歪头看人（如初见风妖怪），眼神探究 |
| 分享时 | 端着一杯花蜜果汁微笑，或递出一块饼干 |

### 小风妖怪（第二篇起）

| 项 | 锁定内容 |
|---|---|
| 身份 | 森林边的贪玩小妖怪；系列常见配角（可再出场） |
| 外形 | 软萌云朵状小妖怪 |
| 身体 | 白色毛茸茸云朵身体 |
| 面部 | 圆圆大眼睛、蓝色小脸 |
| 其他 | 带小翅膀，笑容顽皮 |
| 气质关键词 | 调皮捣蛋、心不坏、有点孤单、爱吃零食 |

#### 性格设定（初稿，可再调）

| 维度 | 内容 |
