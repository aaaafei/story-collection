## 二、本册出场角色

从系列圣经取固定段：**小宝贝玫瑰公主（小宝贝形态）**、蔷薇公主、国王、王后、小风妖怪。

> 本册核心：玫瑰公主还是刚出生不久的小宝贝，蔷薇姐姐上魔法幼儿园，每天全家去接。
> 风妖怪三级捣蛋（吹帽子 → 吹气球花瓣 → 想掀斗篷）用「笑声 + 饼干」化解。
>
> **高发图错（已得结论，生成多角色页务必带以下硬约束句）：**
> 「小宝贝是刚出生的小婴儿，只能被抱在怀里，不会站立；画面中只能出现一位蓝裙小婴儿，
> 禁止小狗、禁止站立的小女孩、禁止第二只小公主」+「画面中只有 N 位角色，禁止额外角色」。
> 风妖怪出场页若与宝宝同框，优先把风妖怪放近景焦点、家人放远景，可显著降低重复角色概率。

**角色固定段（复制用）：**

## 四、验收与常见返工（本册实测）

| 现象 | 原因 | 处理 |
|---|---|---|
| 国王/王后怀里出现小狗 | 模型把「被抱的小婴儿」误画成宠物 | 换挂 `rose-baby-bust.jpg`，并写死「小宝贝只能被抱在怀里、禁止小狗」 |
| 出现站立蓝裙小女孩（宝宝分身） | 参考图是坐姿婴儿，模型顺手补一个站立版 | 写死「画面中只能出现一位蓝裙小婴儿、禁止站立的小女孩、禁止第二只小公主」 |
| 姐姐被画成双马尾 / 金发 / 成年女性 | 角色段被模型弱化 | 明确写「发尾微卷披在肩后、不是马尾辫/不是金发」；亲密动作写「姐姐不抱宝宝，宝宝始终在王后怀里」 |
| 门牌/招牌出现乱码文字 | 模型默认写字 | 写「不要出现任何文字，门牌招牌全部留白」，或把建筑背景换成花园小路 |
| 多人同框必出分身 | 角色过多时参考图互相干扰 | 简化构图：近景只放 2 位关键角色，家人放远景做背景 |
