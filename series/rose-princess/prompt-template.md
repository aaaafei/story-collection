```

【② 角色固定段 —— 从 character-bible.md 原样粘贴本页出场角色】
（示例）两位Q版小公主：浅棕色微卷长发、头戴粉色小花发饰、穿粉红色蓬蓬公主裙的蔷薇公主（姐姐）；蓝色软卷发、头戴蓝色小花发饰、穿蓝色蓬蓬公主裙的玫瑰公主（妹妹）。

【④ 一致性约束】
```

## 封面页额外提示

封面可在可变段末尾加：

```
画面上方可有圆润卡通艺术字「书名」，不要挡住人物脸部。
```

## 反面示例（不要这样做）

- 在可变段里重新发明发色：「金色长发的蔷薇公主……」
- 省略固定段，只写「两个小公主在花园玩」
- 为了好看临时改成红裙子、黑长直
