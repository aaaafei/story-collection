# 蔷薇公主系列 · Prompt 拼装模板

每生成一页，按下面四段拼接。**①②④⑤ 尽量原样固定；主要改 ③。**

---

## 完整模板

```
【① 画风固定段】
儿童绘本插画，马卡龙柔和色系，水彩晕染画风，Q版软萌人物，线条圆润无棱角，光影温柔，画面干净简洁，高清适合打印。人物姿态自然有变化，不要始终正面或单一侧面呆站，需有清晰肢体动作。本页只突出一件可读焦点，画面信息简洁，勿堆砌热闹大场面。

【② 角色固定段 —— 从 character-bible.md 原样粘贴本页出场角色】
（示例）两位Q版小公主：浅棕色微卷长发、头戴粉色小花发饰、穿粉红色蓬蓬公主裙的蔷薇公主（姐姐）；浅黑色软卷发、头戴蓝色小花发饰、穿蓝色蓬蓬公主裙的玫瑰公主（妹妹）。

【③ 本页可变段 —— 场景 / 视角 / 肢体动作 / 表情 / 构图】
场景：……
视角：……（如 3/4 侧面、微俯视、回眸等；避免与上一页完全相同）
肢体动作：……（必须写清手臂、腿在做什么，禁止双手下垂呆站；只服务本页一个焦点）
表情：……
构图重点：……（一句话点出本页唯一可读焦点，例如「她慌了」；勿罗列多件事）

【④ 一致性约束】
严格保持与参考图相同的发型、发色、服装颜色与造型，不要改变角色外观；不要新增夸张配饰。

【⑤ 姿态约束】
本页人物须有明确肢体动作与自然姿态变化；禁止连续多页同一正面/侧面站桩；多角色时姿态与互动要有区分；整页只突出一件能指认的事。
```

---

## 封面页额外提示

封面可在可变段末尾加：

```
画面上方可有圆润卡通艺术字「书名」，不要挡住人物脸部。
```

封面也要有动作（例如浇花、牵手、奔跑），不要纯正面合影呆站。

---

## 反面示例（不要这样做）

- 在可变段里重新发明发色：「金色长发的蔷薇公主……」
- 省略固定段，只写「两个小公主在花园玩」
- 为了好看临时改成红裙子、黑长直
- 只写「蔷薇公主站在花园里微笑」——没有视角变化、没有手脚动作
- 整本书每页都是「正面站立看镜头」
- 构图重点写成「慌了、藤蔓疯长、三人施法、风妖怪偷笑」——一页塞满多件事

## 正面示例（动作写法）

- 「蔷薇公主 3/4 侧面蹲在花坛前，双手捧着小水壶正在浇水，一条腿跪地」
- 「玫瑰公主侧身向前跑，一只手伸向姐姐，裙摆扬起」
- 「姐妹俩微俯视构图：一人踮脚去够花枝，一人在旁拍手」

## 一页一事（构图重点写法）

详见 `style-guide.md`「一页一事」。可变段示例：

- 构图重点：地下公主双手护住裙摆，表情着急慌张（本页只看「她慌了」）
- 构图重点：银色发光藤蔓正爬满花架（本页只看「藤蔓爬上来了」）
- 构图重点：三位小公主一起向前伸手拉住乱藤（本页只看「三个人一起动手」）
