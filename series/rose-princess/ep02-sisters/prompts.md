### 第 1 页 封面

**绘本文字**：百花城堡里，住着最可爱的 —— 蔷薇公主和玫瑰公主！

**配图 Prompt**：
```
儿童绘本插画封面，马卡龙柔和色系，水彩晕染画风。梦幻的百花城堡花园，粉蓝渐变天空飘着软糯白云，远处是奶油色尖顶城堡。画面中心是Q版小公主：浅棕色微卷长发、头戴粉色小花发饰、穿粉红色蓬蓬公主裙的蔷薇公主（活泼可爱），正蹲在花园泥土前，双手轻轻把一颗闪光的玫瑰种子埋进土里，身旁有小铲子和小水壶。周围开满粉色蔷薇花、蝴蝶飞舞。画面上方有圆润卡通艺术字“蔷薇公主和玫瑰公主”。线条圆润无棱角，光影温柔，高清适合打印。
```

### 第 2 页 种出玫瑰小公主

**绘本文字**：蔷薇公主最喜欢种花。她得到一颗闪闪发光的玫瑰种子，小心地种进花园的泥土里，天天浇水、晒太阳。玫瑰花终于开啦——花里竟然变出一位穿蓝色蓬蓬裙的玫瑰小公主！

**配图 Prompt**：
```
儿童绘本插画，马卡龙柔和色系，水彩晕染画风。花园里一朵巨大的粉色玫瑰花盛开，花瓣闪闪发光，花蕊中央坐着一位Q版小公主：蓝色软卷发、头戴蓝色小花发饰、穿蓝色蓬蓬公主裙的玫瑰公主，眼睛亮晶晶，软萌可爱。旁边是穿粉红色蓬蓬公主裙、浅棕色微卷长发的蔷薇公主，惊喜地双手捧脸。背景是彩虹、白云和星星光点。线条圆润无棱角，光影温柔，高清适合打印。
```

**配图 Prompt**：
```
儿童绘本插画，马卡龙柔和色系，水彩晕染画风。阳光明媚的百花花园，两位Q版小公主在草地上追蝴蝶、蹦蹦跳跳：一位是穿粉红色蓬蓬公主裙、浅棕色微卷长发、头戴粉色小花发饰的蔷薇公主（姐姐，活泼调皮，追蝴蝶）；一位是穿蓝色蓬蓬公主裙、蓝色软卷发、头戴蓝色小花发饰的玫瑰公主（妹妹，笑眼弯弯）。花园里开满蔷薇和玫瑰，蝴蝶、小蜜蜂飞舞，气球飘在空中。线条圆润无棱角，光影温柔，高清适合打印。
```

### 第 4 页 小风妖怪抓走姐姐

**绘本文字**：这天下午，调皮的蔷薇公主偷偷跑出花园，想去森林边摘漂亮的小野花。森林里住着贪玩的小风妖怪——「呼——」一阵风卷来，蔷薇公主被带到了高高的树顶小阁楼！

**配图 Prompt**：
```
儿童绘本插画，马卡龙柔和色系，水彩晕染画风。森林边的草地小路上，一只软萌可爱的云朵状小妖怪（白色毛茸茸云朵身体、圆圆大眼睛、蓝色小脸、带着小翅膀，笑容顽皮，不恐怖）卷起一阵轻风，把穿粉红色蓬蓬公主裙、浅棕色微卷长发、头戴粉色小花发饰的蔷薇公主轻轻卷向空中，蔷薇公主表情惊讶。远处是高高的树顶小阁楼。画面有趣不吓人，线条圆润无棱角，光影温柔，高清适合打印。
```

**配图 Prompt**：
