# 蔷薇公主系列 · 画风与生成参数

> 系列共用。各册 `prompts.md` 的参数若与本文冲突，以本文为准。  
> 最后更新：2026-09-13

---

## 画风规范（每张图必须遵守）

- 马卡龙柔和色系（粉蓝渐变天空、奶油色城堡、粉色花园）
- 水彩晕染画风，线条圆润无棱角，画面干净简洁，光影温柔
- Q 版软萌人物，高清适合打印
- 全程无恐怖、无尴尬、无血腥元素
- 反派 / 妖怪必须软萌可爱，不能吓到小朋友

**画风固定段（复制用）：**
```
儿童绘本插画，马卡龙柔和色系，水彩晕染画风，Q版软萌人物，线条圆润无棱角，光影温柔，画面干净简洁，高清适合打印
```

## 生成参数（当前版本）

| 项 | 值 |
|---|---|
| 工具 | 图片生成（image_gen 等） |
| 模型版本 | seedream_4.5（尽量不要中途换模型） |
| 尺寸 | 2304 × 1728（4:3 横版） |
| 导出 | JPEG，建议 quality 85 |
| 命名 | `assets/page-01.jpg` 起连续编号 |

---

## 参考图用法

- 标准照存放：`refs/`（见该目录说明）
- 生成故事页时：挂上本页出场角色的 front / bust 参考图
- Prompt 中加一句一致性约束（见 `prompt-template.md`）

---

## 换模型 / 改画风

若必须更换模型或整体画风：

1. 先更新本文档参数与画风段
2. 用新参数重渲 `refs/` 全套标准照
3. 再按册决定是否重渲旧书关键页（至少封面与人物介绍页）
