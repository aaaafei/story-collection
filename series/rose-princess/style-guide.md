## 画风规范（每张图必须遵守）

- 马卡龙柔和色系（粉蓝渐变天空、奶油色城堡、粉色花园）
- 水彩晕染画风，线条圆润无棱角，画面干净简洁，光影温柔
- Q 版软萌人物，高清适合打印
- 全程无恐怖、无尴尬、无血腥元素
- 反派 / 妖怪必须软萌可爱，不能吓到小朋友

### 姿态与肢体动作（系列出图必须遵守）

同一册、同一系列里，人物**不要几乎每页都是正面站桩或单一侧面**：

| 要求 | 说明 |
|---|---|
| 视角有变化 | 在 3/4 侧面、微俯视、微仰视、背面回眸、半侧面等中轮换；避免连续多页同一朝向 |
| 必须有肢体动作 | 明确写出手脚在做什么（跑、跳、蹲、抱、指、挥手、浇水、拉手、踮脚等），禁止「只露脸、双手垂直贴身」的呆立 |
| 动作服务剧情 | 动作要能看懂这一页在发生什么，与绘本文字对应 |
| 动态感 | 可用轻微前倾、迈步、衣摆/头发随动增强生动，但仍保持 Q 版儿童绘本，不过度夸张扭曲 |
| 多角色同框 | 每人姿态尽量不同，有互动（对视、拉手、一追一跑），不要并排同姿势站齐 |

**禁止（构图僵硬）：**

- 全书人物几乎永远正面面向镜头、双手自然下垂  
- 只有头部转动、身体完全不动  
- 连续 3 页以上同一站姿 / 同一侧面角度  

**姿态提示短句（可写入可变段）：**
```
人物姿态自然有变化，不要始终正面或单一侧面呆站；需要清晰可见的肢体动作（手臂与腿的动作明确），符合本页情节。
```

**画风固定段（复制用）：**
```
儿童绘本插画，马卡龙柔和色系，水彩晕染画风，Q版软萌人物，线条圆润无棱角，光影温柔，画面干净简洁，高清适合打印。人物姿态自然有变化，不要始终正面或单一侧面呆站，需有清晰肢体动作。
```

## 生成参数（当前版本）

| 项 | 值 |
|---|---|
| 工具 | 图片生成（image_gen 等）出**高清源图** |
| 模型版本 | seedream_4.5（尽量不要中途换模型） |
| 源图尺寸 | 2304 × 1728（4:3 横版）建议 |
| 源图存放 | 各册 `assets/src/page-XX.jpg` |
| 网页内页 | 由本地脚本生成，默认最长边 1400px、JPEG quality 82 → `assets/page-XX.jpg` |
| 列表封面 | 同脚本生成 `assets/cover.jpg`（默认最长边 800px） |
| 命名 | `page-01.jpg` 起连续编号 |

**网页用图请在本仓库处理，不要依赖豆包等第三方压缩：**

```powershell
python tools/optimize_images.py series/rose-princess/epNN-主题
```

说明见 [`../../tools/README.md`](../../tools/README.md)。

## 换模型 / 改画风

若必须更换模型或整体画风：

1. 先更新本文档参数与画风段
2. 用新参数重渲 `refs/` 全套标准照
3. 再按册决定是否重渲旧书关键页（至少封面与人物介绍页）
