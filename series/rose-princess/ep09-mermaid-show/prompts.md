## 二、本册出场角色

从系列圣经取固定段：**蔷薇公主（姐姐）**、**小宝贝玫瑰公主（小宝贝形态）**、国王、王后、**小风妖怪（系列常驻配角）**。

> 本册核心：星期六全家开车去看人鱼公主的演出，老朋友小风妖怪也想去，兴奋过头把车吹上了天——
> 追车吹辫带 → 吹飞汽车 → 云间旋转木马 → 零食满天飞 → 玩过头妹妹哭 → 风停车身下坠 →
> 小风妖怪拼命托住车 → 姐姐递饼干原谅 → 温柔的风送到海边，正好赶上演出。全册「化解而非消灭」。
>
> **本册实测高发图错（已踩坑并解决）：**
> - 小宝贝必须写死「刚诞生不久的小婴儿，只能被抱在怀里/摇篮里，不会站立，只露出圆圆小脸」；
>   画面中只能出现一位蓝裙小婴儿。放宝宝椅/高脚椅必被画成幼儿小女孩（ep05 页返工 7 次）。
> - 「王后/国王怀里抱着小婴儿」偶发小狗/玩偶/金发 → 必须写「不是金发、不是小狗、不是玩偶」。
> - 小汽车场景只画可见的 1-3 位角色（如「车窗内王后+小宝贝」「后车窗蔷薇」），车内其他人不画；
>   若只画蔷薇且提到汽车，模型常把她放进驾驶座 → 写「驾驶座方向车窗反光、没有人开车」或干脆车内不画人。
> - 车+人同框必出分身/多余角色 → 近景 1-2 位，远景做背景，写死「画面中只有 N 位角色，禁止额外角色」。
> - 风妖怪偶被画成小羊/松鼠/长角 → 写「白色毛茸茸云朵身体、蓝色小脸、小翅膀，不是动物、没有角」。
> - 蔷薇在人鱼题材页偶被画成美人鱼 → 写「是普通小女孩、没有鱼尾、不是美人鱼」。
> - 画面偶现数字「5」等文字残迹 → 每页写「画面不出现任何文字、数字或字母」。
> - 封面书名用圆润卡通艺术字；其余页面禁止任何文字。

## 四、验收与常见返工（本册实测）

| 现象 | 原因 | 处理 |
|---|---|---|
| 小宝贝被画成幼儿 / 出现第二个蓝裙小孩 | 小宝贝形态弱化 | 写死「刚诞生不久的小婴儿、只能被抱在怀里/摇篮里、不会站立、只露出圆圆小脸、画面中只能出现一位蓝裙小婴儿」 |
| 怀里抱婴儿被画成小狗 / 玩偶 | 模型默认替换 | 写「绝对不是小狗、不是小玩偶」 |
| 婴儿被画成金发 | 与王后发色混淆 | 写「浅黑色软软小卷毛（不是金发）」 |
| 车里只画蔷薇时她被放进驾驶座 | 构图联想 | 写「驾驶座方向车窗反光、没有人开车」或车内不画人，或用「车尾视角」 |
| 车内多角色同框出分身 / 多余角色 | 角色过多 | 每页只画可见的 1-3 位，其余不画；写死角色数量与「禁止额外角色」 |
| 风妖怪被画成小羊 / 松鼠 / 长角 | 「妖怪」与动物混淆 | 写「白色毛茸茸云朵身体、蓝色小脸、小翅膀，不是动物、没有角」；窗台/树梢场景尤其多发，必要时该页不画风妖怪 |
| 蔷薇在人鱼题材页被画成美人鱼 | 主题词诱导 | 写「是普通小女孩、没有鱼尾、不是美人鱼」 |
| 画面出现数字「5」等文字残迹 | 模型默认写字 | 每页写「画面不出现任何文字、数字或字母」 |
| 妹妹坐在宝宝椅/高脚椅必被画成幼儿 | 场景联想 | 改由爸爸/妈妈抱在怀里（本册第 5 页实测 7 次后改为「爸爸怀里」成功） |
