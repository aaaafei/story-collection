## 标准照怎么生成

- 背景尽量简洁（纯色或淡渐变），**不要复杂剧情动作**
- Prompt 只用 `character-bible.md` 的固定段 + `style-guide.md` 的画风段
- 全身照：站立、正面或 3/4 侧面，看清发型、发饰、裙子
- 半身照：看清脸型、眼睛、发饰与领口
- 尺寸与系列一致：2304 × 1728（或同比例裁切）
- 模型：seedream_4.5
