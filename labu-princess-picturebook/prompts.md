## 一、项目概览

| 项 | 内容 |
|---|---|
| 书名 | 拉不下公主（完整版带配图儿童绘本） |
| 适配年龄 | 2-6 岁幼儿 |
| 整体风格 | 调皮搞笑、低幼治愈、无说教、童趣轻松 |
| 交付物 | `index.html`（可直接预览）+ `assets/`（11 张配图） |

## 二、统一画风规范（每张图都必须遵守）

- 马卡龙柔和色系（粉蓝渐变、奶油黄、薄荷绿）
- 线条圆润无棱角，画面干净简洁，光影温柔
- Q 版软萌人物，高清适合打印
- 全程无恐怖、无尴尬元素

## 三、固定人物形象（角色 prompt 片段，可粘贴复用）

- **拉不下公主**：圆脸蛋大眼睛、短发软刘海、浅蓝色蓬松公主蓬蓬裙，灵动调皮
- **屁屁小精灵**：迷你圆滚滚、浅黄绿配色、带小翅膀、捣蛋软萌

## 四、生成参数（当前版本）

- 工具：图片生成（image_gen）
- 模型版本：seedream_4.5
- 尺寸：1536 × 1152（4:3 横版）；页面引用压缩版为 1200 × 900 JPEG
- 图片文件：`assets/page-01.jpg` ~ `assets/page-11.jpg`

## 六、后期调整指南

| 想改什么 | 怎么做 |
|---|---|
| 改某一页画面 | 复制该页 Prompt → 调整描述 → 用 image_gen 生成 → 替换 `assets/page-XX.jpg` |
| 改某页文字 | 直接编辑 `index.html` 里对应的 `<p class="quote">` 段落 |
| 增删页面 | 在 `index.html` 的 `.story` 区块内复制/删除一个 `.page` 卡片，图片命名为连续的 `page-XX.jpg` |
| 统一改画风 | 修改"统一画风规范"后，重跑全部 11 页 prompt |
| 城堡造型 | 封面与彩蛋页 prompt 已内置"双圆顶屁股造型"描述，可继续微调（颜色、大小、数量） |

> 注意：生成新图后请保持 4:3 比例，并在替换后刷新 HTML 确认渲染；转发 HTML 时需连同 `assets/` 目录一起发送。
